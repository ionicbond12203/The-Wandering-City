# AAA Vision

## 产品与当前事实

The Wandering City 是长期开发的原创 Windows 单机第三人称开放世界冒险。玩家应能读懂地标、选择步行/攀爬/滑翔路线、理解战斗反馈，并在退出重返世界时保有可信的进度。探索、战斗、采集、制作与据点建造的已有闭环必须保留。

AAA-quality 指持续一致的体验、表现、可靠性和制作能力，不指团队人数、地图公里数或功能清单。当前整体为 **Prototype**；有局部 Vertical Slice 技术验证，尚未达到完整 Vertical Slice、Production Candidate 或 Production Ready。治理文档完善不会自动改变游戏成熟度。

## 单人长期生产方式

以数据资产、可复用 prefab、离线程序化生成、可视化 authoring、自动校验与版本化证据降低重复劳动。Codex 每次接手都应能从仓库确定真实现状、当前授权范围、系统所有者、验收条件和回滚方法。避免依赖会话记忆、只在本机存在的隐含配置或不断增长的全能管理器。

以现有路线验证能力，再决定是否扩展内容。将一条既有路线制作可靠，比一次规划整张巨型地图更有价值。新的生成算法不能成为隐藏的内容数据库；原始输入、种子、生成器版本、烘焙结果及手工覆盖必须可追踪。

## 体验支柱与评价方式

| 支柱 | 玩家应能感知 | 验收方式 |
| --- | --- | --- |
| 探索可读性 | 看到目的地、辨识岔路、理解可达范围 | 无口头指导的既有路线试玩、固定 Build 视点与路线记录 |
| 操控可信 | 坡面、墙角、落地、攀爬和镜头响应一致 | 行为回归、正常输入试玩、不同帧率记录 |
| 战斗公平 | 预警、命中、闪避与受伤结果可解释 | 窗口边界测试、实际遭遇录像/审查 |
| 世界连续 | 返回地点、传送和重载不丢进度、不重复奖励 | 旧档迁移、加载/卸载、故障恢复及持久化用例 |
| 表现一致 | 角色、环境、声音和 UI 符合原创艺术方向 | 正式资产来源、Build 截图、动作审片、人工试听 |
| 性能稳定 | 正常探索不反复停顿，长时间游戏可继续 | 约定硬件上全路线和长时 profiling，而非平均 FPS |

## 范围约束

本次 G00 只建立 repository governance 和验证契约，不新增地图区域、敌人、任务、武器、玩法或美术内容，不重构运行时系统，不启动 G01。后续路线图同样先重用既有内容验证基础能力。内容扩展须另行授权，不能从本愿景推导为待自动执行任务。

不预设联网、服务端、无限世界、HDRP、ECS 或 Addressables 为必选方案；使用复杂技术须有需求和测量依据。Windows 与 URP 为当前工程基线，最低/推荐硬件与最终发行范围尚未批准。

## 美术真实性

目前角色是原创刚性关节原型，缺少正式蒙皮、Humanoid Avatar 与配套动画；守卫、交互物及建筑仍有程序员美术。配乐槽为空，合成环境声不等于最终配乐或正式混音。树石原创网格与程序纹理也未经最终艺术验收。

允许清楚标注的 placeholder 支撑开发；必须同时维护替换接口、制作规范、来源和 blocker。不能以“生产管线存在”“formalMode”“无粉色材质”宣称正式艺术完成。具体阻塞见 [技术债](TECH_DEBT.md)，阶段晋级见 [质量门槛](AAA_QUALITY_BAR.md)，工作顺序见 [路线图](AAA_ROADMAP.md)。
