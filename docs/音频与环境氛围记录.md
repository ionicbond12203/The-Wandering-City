# Milestone 08：音频与环境氛围

基于 `8074460`，Unity 6000.6.0f1。音频和天气通过 `GameSession` 初始化；不改动旅程存档结构。

## 音频

- `AudioDirector` 使用真实 AudioMixer：Master、Music、Ambience、SFX、UI；快照为 Exploration、Combat、Menu、Interior/Quiet、Paused，切换时间 0.7 秒，暂停时使用非缩放时间。
- `WorldAudio` 资源提供 Menu、Meadow、Forest、Ruins（含采石场）、Combat、Elite 播放列表。区域稳定 3 秒才切换，离战保留 5 秒；精英战优先，离战后返回稳定区域。双声源以 2 秒淡入淡出衔接，快速状态变化排队到当前淡化结束，避免切断仍可听见的声源。
- **仓库没有已授权的正式配乐，全部音乐槽有意留空。** 空槽保持静音，不循环重启、不抛空引用。交叉淡化测试使用临时静音 AudioClip，仅验证路由和增益，不是音乐素材。后续可在 `Resources/WorldAudio.asset` 填入具有可核验许可的曲目。
- 原创合成声音包括风、草地鸟鸣、森林、遗迹、流水和雨声，以及 UI、交互、攻击、受击、拾取、传送、移动动作提示；没有下载第三方音乐。这些是可替换的基础声音设计，仍需真人试听与后续艺术混音。
- 固定 10 个 AudioSource：2 个音乐、6 个环境循环、SFX 和 UI。流水随池塘距离衰减，区域和雨量平滑改变环境声增益。
- 标题与暂停菜单新增声音设置，Master/Music/Ambience/SFX（包含 UI）每次增减 10%，自动保存到玩家目录的 `audio-settings.json`。数值做有限值检查和限幅，临时文件原子替换；测试使用隔离目录。用户增益作用于声源，快照作用于混音组，两者相乘，防止参数覆盖导致暂停压低失效。
- 混音器由 Editor 工具一次性生成并提交。创建资产采用 Unity 6000.6 编辑器内部 API 的隔离反射适配；运行时仅使用公开 AudioMixer API。升级 Unity 后需重新验证生成步骤。

## 水体、天气与光照

- 南部草地 `(-145, -180)` 新增风镜浅池，约 42×26 米，最深约 0.9 米；地形同步开挖，池内清除草与旧装饰，岸边装饰重新贴地。全部探索点保持干燥，不新增游泳机制。
- 原创 URP 水材质包含深浅颜色、动态法线、太阳高光、菲涅耳、岸线泡沫和深度保护的屏幕颜色折射。水面仅 96 个三角形，使用已有 opaque/depth texture，没有额外反射相机。
- `WorldAtmosphere` 配置晴、阴、小雨；18 秒渐变联动云量、天空色、雾、太阳颜色/强度、三色环境光及雨声。自动顺序为晴→阴→雨→阴→晴，停留默认 180/100/75 秒；暂停冻结天气进程。
- 雨采用跟随玩家的局部粒子盒，最多 700 粒子、全雨量 350 个/秒；头顶有遮挡时停止发射，不运行粒子碰撞。没有全地图天气模拟或湿地表系统。
- 调整运行时独立 Volume 的对比度、饱和度、曝光和轻量 Bloom，保留已有 SSAO 与阴影级联方案；没有引入尚未验证的 APV 烘焙流程。晴天暖色、雨天冷灰与距离雾保持角色和交互 HUD 可读。

## 验证与证据

执行 `game/Tools/Verify.ps1 -Build`：完整 EditMode、PlayMode 回归及 Windows 开发构建。新增覆盖区域迟滞、精英/普通战斗及离战返回、暂停/菜单/室内快照、音量存取及坏数据、天气连续过渡、无音乐资源、音乐双源淡化/路由、静音、雨天联动、材质编译和水边装饰贴地。

2026-09-04 最终结果：84 项 EditMode + 38 项 PlayMode，共 122 项全部通过；Windows 构建成功，构建 QA 退出码 0、`passed=true`。7 张 1920×1080 截图已检查，池岸旧装饰悬空已修复，雨丝细化，声音设置未见重叠。构建仍提示已有 Rock/Cliff 网格未来 Unity 版本需要显式启用碰撞预烘焙，当前构建与碰撞回归通过。

本机隐藏窗口采样：六个场景平均帧间隔 16.66–16.69 ms，P95 为 17.40–17.96 ms；小雨 490 个活跃粒子；报告分配内存约 243.5 MiB。场景音频峰值约 0.036–0.197，未发现削波；未进行人工试听。没有目标硬件前台长时性能结论。

Windows 开发构建支持 `-atmosphereQA "绝对输出目录"`。该模式使用隔离旅程与音频设置，驱动真实敌人状态并验证战斗优先级和返回，采集渲染与音频输出后退出。最终证据放在仓库本机忽略目录 `artifacts/atmosphere-qa-final/`：

- `audio-state-log.txt`：逻辑音乐状态、混音快照及空槽记录。
- `weather-clear.png`、`weather-cloudy.png`、`weather-rain.png`：同一池塘视角。
- `water-stream.png`：验收规定的文件名，内容实际为浅池。
- `lighting-forest.png`、`lighting-ruins.png`：区域光照；`audio-settings.png`：实际设置页面。
- `result.json`、`player.log`：断言、粒子数、音频峰值、内存与每状态 120 帧采样。

隐藏窗口帧间隔包含帧率限制，截图耗时还包含离屏渲染与 PNG 编码；这些数字不能替代前台整段 60 FPS 或目标硬件 GPU 性能验收。音频输出采样证明存在非零信号，不能替代人工听感评价。正式配乐仍是明确的素材依赖。
