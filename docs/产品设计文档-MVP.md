# The Wandering City｜MVP 产品设计文档

## 1. 产品方向

一款以第三人称探索与即时战斗为核心的单机开放世界冒险游戏。玩家在可自由探索的区域中发现地点、挑战敌人、收集资源并获得成长。

体验参考《原神》的第三人称操控、场景探索和战斗节奏，同时保留轻量的采集、制作和据点搭建。美术、角色与世界观采用原创设计。

探索战斗是主要体验，采集和建造为冒险提供补给与阶段性目标。采用固定地形，不做整个世界都可挖掘的方块世界。项目名暂用 The Wandering City，不预设移动城市玩法。

## 2. MVP 目标

- 提供约 20～30 分钟的完整体验，验证移动、探索和战斗是否有趣。
- 使用一块小而完整的手工地图，让玩家能自由选择探索顺序和局部路线。
- 跑通从探索、战斗到奖励、升级的循环，为后续扩展内容建立基础。

核心循环：从据点出发 → 发现目标并选择路线 → 探索与战斗 → 获得资源 → 返回据点制作或升级 → 继续探索。

## 3. 主要功能

| 模块 | MVP 范围 |
| --- | --- |
| 角色与镜头 | 一个可操控角色；第三人称镜头、移动、奔跑、跳跃；保证基本操控和碰撞稳定 |
| 探索地图 | 一个出生据点，加树林、矿区、敌人营地三个兴趣点；通过地标、岔路和隐藏奖励鼓励探索 |
| 即时战斗 | 一把近战武器；普通攻击、闪避、生命值、受伤反馈；死亡后回据点重生，暂不设置物品掉落惩罚 |
| 敌人 | 一种近战敌人；巡逻、发现玩家、追击、攻击、死亡与掉落；通过数量和布置形成不同遭遇 |
| 交互与采集 | 统一交互提示；拾取物品、开启宝箱、采集木材、石材和矿石；资源点不改变地形 |
| 背包与快捷栏 | 物品堆叠、数量显示和快捷选择；支持基础材料与恢复道具 |
| 制作与成长 | 一个工作台；制作恢复道具和建筑模块；一次武器升级，使战斗提升可被感知 |
| 轻量据点搭建 | 在据点范围内放置、拆除和回收少量预制模块，如地板、墙体和屋顶；可组合成简单小屋 |
| 目标与奖励 | 一条简短引导目标链；两三个探索奖励点；敌人营地提供用于武器升级的关键材料 |
| 界面与存档 | 生命值、快捷栏、交互提示、当前目标和暂停菜单；支持保存与继续游戏 |

存档至少保留角色位置与状态、背包、武器升级、目标进度、已领取的一次性奖励和据点建筑，避免重新进入后丢失进度或重复领取奖励。

## 4. 首次游玩流程

1. 在据点出生，获得基础武器，通过简短提示学习移动和交互。
2. 在附近采集木材与石材，使用工作台制作恢复道具，放置基础建筑模块。
3. 自由探索树林与矿区，发现宝箱或隐藏资源，练习战斗。
4. 挑战敌人营地，获取武器升级材料。
5. 返回据点升级武器、扩建小屋，完成 MVP 主目标；玩家仍可继续探索。

引导提供方向，不强制玩家按固定顺序探索所有地点。

## 5. 范围与优先级

优先完成角色手感、镜头、基础战斗和一个探索区域；随后接入奖励、背包、升级、引导与存档，形成完整循环；最后补齐轻量建造和体验打磨。若范围超出预期，先缩减建筑模块和配方数量，保留探索战斗与成长闭环。

本版暂不包含：多人联机、无限地图、自由地形挖掘、多角色切换、元素反应、抽卡、复杂剧情、完整技能树、大规模建造、动态天气和完整昼夜系统。攀爬与滑翔留待基础体验验证后评估。

## 6. 验收方向

- 新玩家无需开发者口头指导，即可完成一次探索、战斗、获得奖励和升级的流程。
- 兴趣点容易辨认，玩家能够自主选择路线，并有机会发现目标提示之外的奖励。
- 攻击、受伤和闪避反馈清晰；常规游玩中不出现阻断流程的镜头、碰撞或敌人行为问题。
- 拾取、制作、升级、建造与回收的资源数量正确；死亡重生后仍可继续完成目标。
- 保存并重新进入后，关键进度保持一致，一次性奖励不可重复领取。
- 后续功能改动同步编写或更新相关测试；交付前所有测试和验证通过，并创建对应 Git commit。

## 7. 后续需要确定

正式实现前确定首发平台、游戏引擎与美术方向。当前文档不限定这些技术和制作选择，也不预估开发工期。
