## 路线、遮挡与导航

五条折线道路从旧区域连接到新区域。地形为路径保留可走的缓坡，为每区安排 18m 攀爬台和到达同一顶部的斜坡，并提供离台滑翔路线。隐藏石龛通过交替岩壁形成弯折入口。旧教学区域高度保持原样，远处盆地与连接道路通过过渡带接入。

新增分隔山脊和树林承担渐进揭示。测试从花原、旧城的高处向其余主要地标采样地形遮挡，两个位置均不能看到全部地标；对应 Build 截图用于目视复查。此检查没有宣称穷举世界上每个可能观察点。

旧导航采集体积为 230×110×235m。现在使用一张连通的 NavMesh，输入为按 3m 网格截取的实际玩法地形，以及相关静态碰撞体；不把整个 Terrain 加入导航。外部 Bounds 为 730×210×715m，但输入地形掩码只占整张 Terrain 约 21.39%，含 50,170 个输入三角形。远景山体没有进入该地形网格。区域间的连接道路与旧区域属于同一导航数据，避免多张独立 Surface 的边界断路。

地图烘焙同步更新，未配置探索路线的地形降暗；HUD 在远景荒野显示明确提示。信标增至 7 个后，全图改为点击标记再传送，避免旧按钮列表越过菜单边界。

运行 `game/Tools/Verify.ps1 -Build`。105 项测试：74 EditMode、31 PlayMode。包含规模、区域间距、遮挡、重复 ID、所有奖励可达位置、新信标完整路径、安全传送、远处存档、真实场景重建后的奖励状态、五条攀爬滑翔路线，以及之前的战斗、建筑、地图和存档回归。
