# Demo 体验说明

这是用于评估整体界面和操作流程的单机前端原型。物品、敌人、战斗结果和场景进度均使用模拟数据，不连接真实后端。

## 推荐体验顺序

1. 在「风息原野」采集木材，打开背包检查资源变化。
2. 通过地图前往「旧日采石场」，采集石材。
3. 返回「旅人据点」，在工作台制作恢复药剂。
4. 前往「遗迹营地」，尝试攻击、闪避和恢复生命，击败守卫后领取奖励。
5. 回据点升级武器，并在建造界面放置或回收建筑模块。

## 评估重点

- 当前目标和可交互对象是否容易发现。
- 地图切换、背包查看、工作台制作的操作是否清晰。
- 战斗反馈和资源不足提示能否帮助理解结果。
- 升级和任务进度是否形成明确的反馈。

## 原型边界

场景用于表现探索氛围；位置切换与战斗为交互模拟，不代表最终 3D 地形、物理、寻路或实时动作系统。进度仅保存在当前浏览器本地，可从设置重新开始。
