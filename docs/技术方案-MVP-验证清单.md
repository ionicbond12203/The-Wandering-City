## 2. Unity 实现阶段测试用例

以下用例均待 Unity 工程实现后执行，并记录编辑器版本、构建版本、环境、实际结果与失败证据。

| 编号 | 类型 | 操作与期望结果 |
| --- | --- | --- |
| T01 | Play Mode + 人工 | 在坡面、台阶、墙角和狭窄区域移动跳跃；无穿透、持续悬空或镜头阻断 |
| T02 | Play Mode | 同一次攻击多帧命中同一敌人只扣血一次；隔墙不命中；死亡后不再攻击 |
| T03 | Play Mode | 闪避窗口内免伤，窗口外正常受伤；菜单输入不会触发战斗动作 |
| T04 | Play Mode | 敌人巡逻、发现、追击、攻击、返回、死亡转换正确；不可达位置不持续造成伤害 |
| T05 | Edit Mode | 拾取与堆叠数量正确；容量不足、材料不足等失败操作保持原状态 |
| T06 | Edit Mode | 制作、升级、放置、回收的扣除与获得一致；一次升级不能重复扣料或生效 |
| T07 | Edit Mode + Play Mode | 连续交互、离开返回及读档后均不能重复领取一次性奖励 |
| T08 | Edit Mode + Play Mode | 提前探索矿区或击败营地后仍能推进引导；关键升级材料可领取且不会因重载丢失 |
| T09 | Play Mode | 越界、重叠、无支撑或阻挡关键通路时不能建造且不扣料；有效放置后资源与实例一致 |
| T10 | Play Mode | 有依赖的建筑不可直接拆除；背包满时回收失败且建筑保留；成功回收不重复发放材料 |
| T11 | Edit Mode + Play Mode | 保存后退出重开，角色、背包、快捷栏、升级、目标、奖励、世界状态与建筑一致 |
| T12 | Edit Mode + Play Mode | 模拟写入中断、主档损坏、未知版本和非法配置 ID；按方案恢复或提示，原档不被静默覆盖 |
| T13 | Play Mode | 死亡后回据点，背包和进度保留；死亡存档或非法位置读档后可继续操作 |
| T14 | 人工 | 新玩家无口头指导完成探索、战斗、奖励和升级；能识别兴趣点并自由选择路线 |
| T15 | Windows 构建 | 在记录的参考硬件和画质下完成整段游玩，记录帧耗时、内存和 GC；达到确认后的性能目标 |
