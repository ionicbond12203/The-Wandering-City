## 替换正式角色

1. 将拥有合法授权的模型及许可证加入项目；建立一个脚底原点、朝 +Z、米制尺寸、根缩放为 1 的 prefab 包装层。模型约 1.8–1.9m 高，Animator 保留有效 Humanoid Avatar，动作使用 in-place 导入设置。不要给包装层加 Gameplay Motor。
2. 在 prefab 根添加 `CharacterRigBindings`，将 Weapon、Back、Glider、CameraFocus、Head、Vfx 拖入对应挂点。显式引用优先，其次在后代中查找标准名称，最后由 Humanoid 的右手、胸部、头、髋骨生成默认点。艺术家应调整挂点的局部旋转与位置，以适配握柄和背部佩挂。
3. 菜单 `Create > Wandering City > Character animation set` 创建资源，在 Clips 中按状态名填齐 17 个动画。将资源指定给 bindings 的 Animations；Humanoid 动画必须与该 Avatar 兼容。动画的源骨架及重定向质量属于资产验收项目。
4. 将 prefab 指定到 `Resources/CharacterPresentation.asset` 的 `CharacterPrefabSlot`，即可在正常游戏启动时选择它，无需修改 WorldBuilder、PlayerMotor 或 PlayerTraversal。也支持直接在 adapter Inspector 指定 slot，或调用 Setup(motor, prefab)。优先级为调用参数、adapter 已指定资源、全局设置、内置原创原型。
5. 接入后复跑本文测试及实际构建截图。默认生成器只重建内置 Traveler 原型，不覆盖指定的外部 prefab 或动画集。

`CharacterAnimationSet.Complete` 检查状态动画是否齐全；`CharacterVisualAdapter.MissingAuthoredAnimations` 暴露缺失情况。未填齐的 slot 仍回落到原型曲线，**这些 Generic 曲线不会自动变成 Humanoid 动画**，必须补齐再交付正式角色。不能仅凭 prefab 成功实例化判断正式资产验收通过。

## 组件与挂点

玩法根保留独立的 CharacterController。`PlayerVisualRoot` 容纳渲染 prefab；所有导入视觉 Collider 被禁用，Rigidbody 设为 kinematic 且禁止碰撞，所有 Animator 关闭 root motion，仅主 Animator 启用。动画只驱动视觉层级，攻击判定、速度、体力、攀爬探测和碰撞仍属于原玩法组件。

Weapon 跟随右手，Back 跟随胸部；攀爬、翻越、滑翔和死亡时武器移到背部。Glider 和 CameraFocus 挂在稳定的视觉根，避免步态骨骼让风帆、镜头来回抖动。Head 和 Vfx 可供后续视线、命中特效使用。SecondaryMotion 提供围巾、斗篷、行囊挂钩，目前仅做有限角度摆动，不启用布料仿真。

重复 Setup 会关闭并清除旧视觉实例，保留唯一动画驱动器；自定义 slot 不会被默认 Traveler 覆盖。

## Animator 架构

`Traveler.controller` 使用一层 Full body，由 `CharacterAuthoring` 确定性生成。Locomotion 是按实际位移速度混合的 Idle / Walk / Run / Sprint Blend Tree，阈值取 Balance 的 0 / 2.4 / 4.8 / 8m/s。移除旧的整个人物上下摆动，遇墙没有位移时步态回到 Idle。转向采用按时间计算的指数平滑。

其余状态为 JumpStart、Fall、Land、Dodge、Attack1/2/3、Hit、Death、ClimbIdle、ClimbMove、LedgeTransition、Glide。Land 通过下落速度得到 LandImpact，并在 Idle 与落地缓冲姿态之间混合。攀爬传入 ClimbX / ClimbY / ClimbRate，下攀反向播放，横向输入也会输出给替换动画的表现扩展。滑翔使用稳定抬臂姿态和独立风帆挂点。

参数：MoveSpeed、VerticalVelocity、Grounded、Sprint、Climb、Glide、AttackIndex、Dodge、Hit、Dead；辅助参数为 Pose、ActionPhase、ClimbX、ClimbY、ClimbRate、LandImpact、Turn。Pose 是代码统一仲裁后的状态：死亡优先于受击、闪避、攻击、攀爬、滑翔和普通移动，避免多个 AnyState 条件同时争抢。过渡使用 0.06–0.12s 混合，不等待剪辑结束。

攻击、闪避和受击动画的 normalized time 由 ActionPhase 驱动。攻击命中窗口仍为 Balance.attackWindup 到 attackHitEnd，恢复由 attackRecoveryEnd 决定，完全不读取 AnimationClip.length。恢复期允许缓存下一击（最多三段）或闪避取消；起手与命中期禁止取消。每次挥击独立清空命中去重集合。暂停、死亡、受击和读档会阻止或重置相应动作，连段不写入存档。

## 已知边界

没有启用足底 IK。当前原型已能摆臂、屈膝和切换动作，但足底没有锁定到接触面，斜坡和快速转身仍可能出现滑步、脚掌倾角不匹配或关节穿插。正式蒙皮、面部细节、手指握持、动画重定向以及最终动作审美需要合法美术资产与后续调校。头部/VFX 挂点是接口，未新增视线求解器或特效系统。未改动敌人战斗系统、存档 schema 或世界导航。

提交前清理了 Unity 重建造成的无语义变化：环境 prefab 与四份树 prefab 共 1,741 个序列化对象，规范化本地引用及外部 prefab 引用后，用 14 轮图哈希比较确认等价，保留原始文件。生成版本的字节备份位于 artifacts/character-generated-backup。
