# 开放世界拓扑与视觉重建

## 基线与根因

基于 main / e00a841。旧高度场把 -78..92 × -32..162 的矩形核心压至约 3 厘米起伏，外部 SmoothStep 的第三参数未经归一化，导致迅速升高成为围墙。树冠、岩石、台地与旅人仍依赖内置 primitive；草只有独立 prefab；相机未显式打开后处理；自定义环境 Shader 未应用雾。

## 生成架构

TerrainHeightModel 以米为单位提供确定性 Sample，包含多频滚动噪声、森林丘陵、采石场、遗迹高地、蛇形低谷、非对称山峰与局部安全地面。Terrain 为 1024 × 1024m，160m 高度容量，513 高度图，原点 (-512,0,-420)。生成版本持久化在 TerrainData 名称，不再依赖机器级 EditorPrefs；更新原资源，保留 GUID。

OriginalMesh 使用原创环截面放样、三角草叶和分面网格，没有下载外部素材。OpenWorldAuthoring 把网格保存为可复用 Unity 资源。树有 A/B/C 三变体、弯曲树干、方向不同的枝干和不对称冠层；每套树、岩石、悬崖均有 LOD。树林实例共享资源并改变旋转/比例。草为 GrassShort、GrassTall、FlowerDetail、SmallPlant 四种 GPU instanced Terrain Detail，1024 密度图；排除主要道路、建造场、攀爬设施、陡坡、沟底与主要交互区域。近景绘制距离 70m。

Environment 下保留原容器，并新增 Midground / DistantLandscape。外围离散山体不带碰撞、不投射阴影，通过 LOD 和雾融入地平线。北方 205m 处添加观测塔地标。编辑器生成的完整环境同时保存到 Resources prefab，直接创建 GameSession 的测试/入口也使用一致环境。

## 路线与锚点

- A：出生草甸 → 西北森林 / 东北采石场 → 北方遗迹。
- B：东侧步行坡道 → 中层平台 → 台地；石壁提供攀爬捷径，高台提供滑翔起点。
- C：地标 → 风隙谷地 → 双石共鸣 → 宝箱。

GroundPoint 与 GroundY 统一地面加局部偏移。玩家读档时抬高埋在新地表下的位置，不变更 stable ID 或 v2 存档 schema。旧保存高度高于新地面时仍由重力落地。坡道入口随地面变化；装饰悬崖移出资源交互范围，stone-9 从峡谷崖面移到 (79,61) 采石场平台。NavMesh 只烘焙现有玩法范围（230 × 110 × 235m），远景不参与昂贵的运行时导航生成。

## 天空、光照与相机

WanderingCity/StylizedSky 以三频噪声形成缓慢漂移云层，提供天顶/地平线颜色、雾霭、云覆盖/柔度、曝光。太阳方向直接取 URP 主方向光，软光晕与云影层次保持原创。继续使用 URP、Global Volume、SSAO、四级联阴影；阴影距离 100m。主相机显式启用 post processing，Cinemachine 镜头和 Camera 均设置 1200m far clip。默认俯角 12°，保留碰撞、变焦、攀爬与滑翔镜头行为。环境和草 Shader 加入空气透视。

## 角色与 HUD

角色为原创低多边形旅人占位，有四肢、靴子、斗篷、围巾、偏置行囊及武器接口。保留 CharacterVisualAdapter / CharacterPrefabSlot，可替换正式角色。并非完成的 anime Humanoid / SkinnedMesh 美术，现有动画仍属原型。HUD 保留生命、体力、目标、快捷栏和交互，降低面板不透明度；操作提示只在 DevelopmentVisualMode 显示。

## 验证

实际执行 `game/Tools/Verify.ps1` 和 `game/Tools/Verify.ps1 -Build`。最终 EditMode 56/56，PlayMode 26/26，Windows 构建成功。EditMode 覆盖确定性、高度连续性、开口、四种草原型及密度、变体 LOD、正式环境 primitive 审计、迁移柱体尺寸、天空/材质编译。PlayMode 的墙体、战斗和探索测试改为地形相对夹具，保留奖励可达性与原断言；另检查真实相机后处理与 far clip。

构建后以 `-screen-fullscreen 0 -screen-width 1920 -screen-height 1080 -qaOutput "<仓库>/artifacts/visual"` 启动 Windows exe，实际可见窗口执行完整 Build Smoke。退出码 0，日志包含 `WANDERING_CITY_SMOKE_OK`，smoke-result.json 的 passed 为 true；未发现异常或不支持 Shader 的错误。测试使用独立存档目录。验证 XML 与构建日志在 `artifacts/`，不纳入版本库。

## 性能

设备：Intel Core Ultra 9 285H / Intel Arc 140T，Unity 6000.6.0f1，1920×1080 Development Build。截图完成后采样 300 个原生游戏帧：平均 16.77ms，P95 16.67ms，记录 FPS 60.06；CPU 主线程 16.60ms（包含帧率限制等待），GPU 5.70ms，Unity allocated memory 227.55MB，GC 约 2543 bytes/frame，采样期间 1 次 collection。Batches / Draw Calls 返回无有效数据，输出 -1，尚未完成这两项性能验收。此结果不是全路线持续性能基准。

真实 Terrain Detail 使用 InstanceCountMode，整张地图密度数值合计 412119；它是分布总量，不是每帧可见实例数。原生帧截图可见草叶与阴影。旧离屏 RenderRequest 没有正确绘制草的颜色，已改为 WaitForEndOfFrame 后读取 ScreenCapture 原生 framebuffer。

## 已知边界

APV 未自动烘焙，列为后续增强。旅人不是正式蒙皮角色；建筑、守卫、交互道具与部分碰撞设施仍属于原型资产。树冠、坡道和台地仍有明显的低多边形原型风格，不宣称完成正式 anime 美术。现有玩法范围之外是可浏览地景，没有扩展敌人导航和任务。自动性能采样是短时测量，不能代替完整路线持续 60 FPS 验收。
